# 全距离科学跑步训练知识库目录（Knowledge Base Index · 800m & 3K–Marathon）

本知识库由同行评审期刊论文、开放获取博士论文以及经典田径/路跑执教实践梳理而成，覆盖 **800m 专项** 与 **3K / 5K / 10K / 半程马拉松 / 全程马拉松** 全距离周期训练、恢复门控与科学补给决策。

## 一、全距离实操手册与证据档案

### A. 3K–全马中长跑与马拉松体系（3K / 5K / 10K / HM / Marathon）
1. **[distance-training-bible.md](./distance-training-bible.md)** — **3K–全马科学训练生理学与周期手册**
   - 3K / 5K / 10K / 半马 / 全马四支柱权重（`VO2max`、`LT2`、`RE` 与第四维度 `Durability` 生理耐久度）
   - VDOT / Riegel 跨距离外推边界、金字塔→极化分布、分段阈值控制、全距离独立 `Taper`（7–21天）与半马/全马碳水补给及肠道训练协议
2. **[distance-session-catalog.md](./distance-session-catalog.md)** — **3K–全马 10 大标准化课表决策卡库**
   - 覆盖 `DIST-EASY-AEROBIC`、`DIST-STRIDES`、`DIST-THR-CRUISE`、`DIST-THR-TEMPO`、`DIST-VO2-3K5K`、`DIST-10K-SPECIFIC`、`DIST-HM-SPECIFIC`、`DIST-LONG-PROG / DIST-MP-BLOCK`、`DIST-FUEL-GUT`、`DIST-TAPER-SHARP / DIST-STR-ECONOMY`

### B. 800m 中距离专项体系（800m Specialist）
3. **[800m-interval-bible.md](./800m-interval-bible.md)** — **800 米生理学与间歇分类参考手册**
   - 供能特征、当前能力与远期目标分离、ASR/SRR 估算边界与按目的划分的间歇/冲刺规范
   - 力量转化与非预设诊断的疼痛安全门控
4. **[interval-session-catalog.md](./interval-session-catalog.md)** — **800 米标准化田径场与力量课表库**
   - `Module A (Strides/加速/MSS/短坡)`、`Module B (阈值/短间歇/长间歇)`、`Module C/D (比赛节奏/拆分 800m/Taper)`

### C. 通用底层方法与证据登记（全距离共享）
5. **[polarized-training-bible.md](./polarized-training-bible.md)** — **强度分布与速度目的实用指南**
   - 个人暂定轻松跑心率护栏（非实测 LT1）、描述性极化指数 `PI` 的边界、各速度带目的与组休对照
6. **[evidence-notes.md](./evidence-notes.md)** — **证据分级、研究局限与历史勘误表（不注入运行时 Prompt）**
   - 逐条列出研究对象、研究类型、主要结果、适用限制与出处，明确区隔 `[论文结果]` / `[教练经验]` / `[个人暂定规则]` / `[程序估算]`
